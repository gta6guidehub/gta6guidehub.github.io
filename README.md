# GTA 6 Guide Hub

Unofficial fan guides, calculators and tips for Grand Theft Auto VI (released November 19, 2026).

## Tools (all run in the browser, no server needed)
1. In-Game Earnings Calculator — hourly rate vs. item price, time to afford it.
2. Heist Payout Splitter — leader bonus off the top, remainder split equally.
3. Vehicle Cost & Speed Comparison — compare any two vehicles side by side.
4. Mission Checklist Tracker — story missions saved in localStorage.
5. Completion Progress Tracker — story 60%, side activities 25%, collectibles 15%.

Also included: a vehicle comparison reference table (community estimates), six full guides,
and an FAQ. All prices, speeds and payouts are community estimates / in-game approximations,
never official Rockstar Games data.
